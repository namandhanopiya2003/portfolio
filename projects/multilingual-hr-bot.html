Multilingual HR Bot

A smart HR assistant that answers employee queries about payroll, leave, and updates using GPT-powered APIs. It supports multiple languages and is built for easy integration, making it ideal for global teams and internal support systems.

Technologies Used

Python
OpenAI API
Flask
REST API
NLP

Challenges Faced

Making the chatbot work in different languages was tricky because each language has its own quirks. I also had to make sure it could handle user's requests and respond properly if any failure happens.

What I Learned

Learned how to connect OpenAI APIs with Flask, handle multilingual inputs, build fallback systems, and design scalable, secure chat interfaces that perform well under real-world usage.
