Movie Recom­mendation System

A collaborative filtering recommendation system that uses the MovieLens dataset to analyze user preferences. It predicts personalized movie suggestions by combining matrix factorization with content-based and behavior-driven insights.

Challenges Faced

Managing sparse rating data and tuning parameters like similarity scores and normalization was challenging. I also had to ensure the system remained scalable and personalized, even for users with limited past activity, which required thoughtful design choices.

What I Learned

I gained practical experience with collaborative filtering, transforming user-item matrices, and evaluating models using precision, recall. Also learned to build complete recommendation systems using R and the recommenderlab package.
